# A Little Date for Olya ♡

Персональное интерактивное приглашение: конверт → романтичное письмо → фото → вопрос → детали → мини-опрос → приглашение на память.

## Запуск

```sh
npm install
npm run dev
```

Открой адрес из терминала. Для просмотра на телефоне в той же Wi-Fi сети запусти `npm run dev -- --host 0.0.0.0` и открой Network URL. Компьютер должен разрешать входящее подключение.

## Настройка

- Все основные тексты, имя, кафе, время, варианты опроса и длительности анимаций: `src/config/invitation.ts`.
- Текст письма: `letterGreeting`, `letterParagraphs`, `letterClosing` в том же конфиге. Письмо остаётся на экране до нажатия кнопки. На последующих экранах иконка конверта вверху позволяет перечитать его, сохранив ответы.
- Добавь своё фото в `public/images/our-photo.jpg`. Пока его нет, показывается оформленная заглушка «Our photo». JPEG с вертикальной или квадратной композицией подходит лучше всего.
- Добавь свой аудиофайл в `public/music/background.mp3`. Музыка запускается только кнопкой, автоматически не включается. Если файла нет, появится сообщение. Используй музыку, на которую у тебя есть право.
- Файлы из `public` доступны по `/images/...` и `/music/...`, без `/public` в URL.
- Все шрифты включены в сборку, обращения к Google Fonts нет.

## Поведение

Ответы и текущий экран хранятся только в localStorage этого браузера. Опрос сохраняет выбранный день как локальную календарную дату `YYYY-MM-DD`, без смещения часового пояса. Четверг и воскресенье показывают ближайшие соответствующие даты после 19:00; четверг отмечен как предпочтительный, но автоматически не выбирается. После 19:00 сегодняшний вариант переносится на следующую неделю. Можно выбрать и другую дату. Прошедшие и некорректные сохранённые даты сбрасываются при следующем открытии. Финальная карточка доступна только после выбора даты и плана.

«Сохранить приглашение» создаёт PNG размером 1200 × 1600 с выбранными деталями. На iPhone файл появится в загрузках Safari; его можно сохранить в Фото через меню «Поделиться».

«Отправить мой ответ» открывает Telegram Share с заполненным сообщением и ссылкой на сайт. Получателя и отправку выбирает сама Оля. Ответы никуда автоматически не передаются. При просмотре с localhost ссылка в сообщении тоже локальная — для отправки используй опубликованную версию.

Кнопка «Нет» убегает до пяти раз при наведении мыши, касании или активации клавиатурой. Крестик сверху всегда позволяет закрыть приглашение; возврат доступен без потери ответов. При изменении размера окна положение убегающей кнопки сбрасывается. `prefers-reduced-motion` отключает декоративное движение и сокращает переходы.

На фоне поднимаются сердечки и искорки; печать конверта и декоративные сердца мягко пульсируют. Нажатия на кнопки, варианты опроса и письмо вызывают короткие всплески сердечек. После согласия и на финальном экране появляется конфетти, у финального сердечка расходятся кольца. На телефоне видны 16 фоновых частиц и до 32 частиц конфетти; одновременно допускаются не более трёх всплесков, которые автоматически удаляются. Эффекты не перехватывают нажатия и прокрутку. Количество и длительности задаются в `animation` конфига. Настройка уменьшенного движения применяется и при её переключении на уже открытой странице.

```sh
npm run check

```

## Vercel

Импортируй папку проекта в Git-репозиторий и подключи его в Vercel. Настройки:

- Framework preset: **Vite**
- Build command: `npm run build`
- Output directory: `dist`
- Node.js: **22.x**
- Переменные окружения не нужны.

Приложение статическое: сервер, авторизация и база данных не требуются. Маршрутизация внутри React state, поэтому rewrite для вложенных URL не нужен.

## Что проверено

Production-сборка проходит TypeScript и Vite. В Chromium пройден полный сценарий, включая наведение мыши и эмуляцию касаний кнопки «Нет», пользовательскую дату, восстановление и изменение ответов, подготовленный Telegram URL и загрузку PNG. Экспортированное изображение проверено визуально. Проверены ширины 320, 390, 768 и 1440 px, режим уменьшенного движения, повреждённые/просроченные данные и недоступный localStorage.

После добавления романтичного письма выполнены 52 дополнительные браузерные проверки: все семь экранов на размерах 320×568, 360×640, 375×667, 390×844, 430×932 и 844×390; читаемый текст письма 16 px; кнопки шапки с областью нажатия 44×44 px; перечитывание без потери ответов; полный сценарий на ширине 320 px. Горизонтального скролла и выхода карточек/кнопок за края не обнаружено. Письмо прокручивается вместе со страницей, без внутреннего скролла и таймера закрытия. Снимки: `output/playwright/romantic-letter-320.png` и `romantic-letter-390.png`.

Физический iPhone и Safari не тестировались. Настоящее фото и аудиофайл пока не добавлены: проверены заглушка и сообщение об отсутствии музыки. Публикация на Vercel не выполнялась. Снимки проверки и браузерные сценарии сохранены локально в `output/playwright/` и исключены из Git.
